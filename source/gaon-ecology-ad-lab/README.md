# 가온시 환경교육센터 푸른순환

사이트 5의 모집요강 기반 모의 테스트 환경입니다. 기관·작성자·관측값·교육 일정·광고는 합성 자료이며 실제 기관이나 공식 심사 사이트와 무관합니다. 실제 예약·거래·연락 기능을 제공하지 않습니다.

## 실행

코디네이터가 저장소 루트에서 빌드·배포 동기화를 수행합니다.

```powershell
node source/manage.mjs build 5
node source/manage.mjs check
node --test source/site-tools.test.mjs
```

빌드 후 프로젝트 폴더에서 `npm start` 또는 `START_LOCAL.cmd`를 실행합니다. 포트는 등록 정보의 기본 4177입니다.

- 로컬 시작: `http://127.0.0.1:4177/index.html`
- 로컬 검증실: `http://127.0.0.1:4177/lab/index.html`
- 저장소 시작 경로: `test-site-5/index.html`
- 저장소 검증실: `source/gaon-ecology-ad-lab/dist/lab/index.html`

런타임은 외부 의존성 없는 정적 HTML/CSS/JavaScript입니다. 브라우저 검사에는 개발 의존성 Playwright 1.63.0과 설치된 Chrome을 사용합니다. `CHROME_PATH`로 실행 파일을 지정할 수 있습니다.

```powershell
npm run check
npm run verify
```

검사는 빌드된 파일을 읽으며 동적 포트의 임시 정적 서버를 시작·종료합니다. 실제 결과 JSON·비교 입력·스크린샷은 `artifacts/`에 기록합니다. 독립 검증 상태는 `VERIFICATION.md`에서 확인합니다.

## 탐색과 대기

시작 URL에서 실제 내부 a[href]와 iframe을 따라 탐색합니다. 가장 깊은 T34 기록은 `observations/wetland/2026/autumn/read.html`이며 시작 깊이0부터5개의 링크를 따라야 합니다. 직전 가을 자료철에서 링크가900ms 뒤 생성됩니다. 이 글은 목록·검색 데이터·홈의 직접 링크에서 제외하여 우회 경로가 없습니다.

- 관측 의견: T25 400ms, T26 1800ms, T27 2800ms. 정상 접근성 N12 900ms.
- T30: 외부 iframe900ms, 마지막 프레임 안 메모400ms. 부모 로딩 기준 nominal1300ms이며 프레임 문서 로딩 시간이 더해질 수 있습니다.
- 프레임: T28 1단계, T29/T30/N08 3단계. 동일 출처입니다.
- 권장 viewport1440×1000, 모바일 검사390×844. 페이지별3.5초 이상 대기한 후 링크·프레임·동적 DOM을 수집합니다.

`station=wetland/stream/garden`과 `season=spring/autumn`을 함께 유지하여6본문을 구분합니다. 파라미터 순서와 fragment는 중복 처리하며 쿼리 값은 보존합니다. 프레임은 독립 시나리오로 재집계하지 않고 부모 URL과 바깥부터 이어지는 frames로 기록합니다. 같은 원점·배포 경로의 HTML만 탐색하며 widgets의 독립 URL·lab·.invalid 외부 주소는 제외합니다. 새 URL이 없으면 종료합니다. 모든 내용·지연은 고정이고 무작위 또는 무한 페이지가 없습니다.

## 검증실과 배포

공통 lab 알고리즘·스키마·UI 명칭을 유지합니다. 필터·검색·주소 복사·다운로드·전수 요소 검사·시작 URL BFS·결과 파일 비교를 제공합니다. 결과 파일은 브라우저 내부에서 처리합니다. 실제 같은 유일 요소를 가리키는 다른 선택자를 인정하고 중복·모호한 선택자·필드/JSON/BOM 오류·쿼리·iframe을 구분합니다. 원문은 필수 필드지만 문자열 차이만으로 위치·기법 정답을 오답 처리하지 않습니다. 예상 결과0초는 합성 예시이며 공식 점수나 실측 실행 시간이 아닙니다.

브라우저 검사 기대값은 정의와 manifest에서 산출합니다. 58요소 DOM·52URL BFS·검색/초기화/빈 결과/페이지네이션·모든 지연·3단계 프레임·6쿼리·비교 입력·데스크톱/모바일·JS 오류·넘침을 확인합니다. 기존 사이트1~4의 완전 정답 회귀도 확인하며 사이트1의 텍스트 결과 표시 호환 처리를 보존합니다. 단독 dist와 로컬 저장소 접두 경로에서 결과 비교·DOM 감사를 검사합니다. 접두 매핑은 실제 원격 배포 검사와 별도입니다.

`src/`는 사례·화면·검증실, `scripts/`는 생성기/서버/검사, `dist/`는 정적 결과, `reference/`는 정답·수량, `artifacts/`는 실제 증거입니다. `test-site-5/`에는 대상 파일만 배포하며 검증실·정답·소스 링크를 제공하지 않습니다. 독립 dist 호스팅에서 정답 비공개가 필요하면 lab을 제외합니다. 분리는 접근 제어가 아닙니다. 기존 형식을 유지하며 release·ZIP을 추가하지 않습니다.
