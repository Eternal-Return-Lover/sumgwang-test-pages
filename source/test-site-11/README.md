# 새봄시 소비자안전센터 생활나침반

소비자 상담과 생활안전 정보를 나누는 가상의 시민 포털입니다. 크림·차콜·코럴 색상의 편집형 화면에서 상담 이야기, 분야별 자료, 생활기록을 읽습니다. 기관·인물·광고는 합성이며 실제 상담 접수·거래·연락·개인정보 수집 기능은 없습니다. 11개 광고 주제는 팀 자체 모의 범위이며 공식 분류가 아닙니다.

저장소 루트에서 실행합니다. 공통 의존성·서버를 사용하며 사이트별 설치는 필요하지 않습니다.

```powershell
npm ci
npm run build -- 11
npm run check -- 11
npm start -- 11
```

- 탐지기 입력: [test-site-11](http://127.0.0.1:4183/test-site-11/)
- 결과 업로드: [공통 대시보드](http://127.0.0.1:4183/validator/?site=11)
- 사례·원문 확인: [상세 검증실](http://127.0.0.1:4183/source/test-site-11/lab/)
- 대상 배포본: `test-site-11/`; 단독 생성물: `tmp/build/test-site-11/`
- 정답·집계·합성 제출 예시: `source/test-site-11/reference/{ground-truth,counts,expected-result}.json`

대시보드에서 사이트 11을 선택하고 도구의 `result.json`을 올립니다. 파일은 브라우저 안에서 처리합니다. 검증실의 예상 결과 다운로드는 현재 접속 주소를 사용하며, 보관용 예시는 루트 설정의 공용 주소와 고정 합성 시각을 사용합니다. `meta.topic`은 `TOPIC`, finding은 기존 여섯 필드입니다. 카테고리는 제출 필드가 아니라 정답의 주석입니다.

정의 집계는 **65개 콘텐츠 URL(정적 59 + 쿼리 6), 양성 44개·정상 22개 요소, 기대 검출 55건**입니다. 11개 주제마다 양성 4개·정상 2개·기대 검출 5건이며 네 기법을 모두 포함합니다. 같은 글의 형제 프레임 두 요소와 복합 기법 11개 때문에 URL·요소·검출 건수가 다릅니다. 상세 수량·배치와 HTML 파일 수는 [REQUIREMENTS.md](REQUIREMENTS.md)에 구분했습니다.

사이트 고유 **기본 검사**는 빌드 후 실행합니다. Chrome 경로를 바꾸려면 `CHROME_PATH`를 지정합니다.

```powershell
npm run verify -- 11
```

검색·필터·초기화·6쪽 목록·쿼리 6분기·형제 프레임·고정 지연·6단계 실제 링크·1440/390/320 화면을 확인하고 `tmp/verification/test-site-11/`에 JSON과 스크린샷을 남깁니다. 전체 DOM·비교 오류·대시보드·이전 사이트·접두 및 단독 배포 검사는 공통 도구와 별도 독립 검증 범위입니다. 기본 검사는 공식 심사나 탐지기 성능 평가가 아닙니다. 실제 실행 결과와 검사 범위는 [VERIFICATION.md](VERIFICATION.md)를 참조하세요.
