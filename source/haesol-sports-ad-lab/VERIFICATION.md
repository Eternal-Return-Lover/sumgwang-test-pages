# 실제 검증 기록

검증일: 2026-10-05 (Asia/Seoul). Node.js 24.14.0, 설치된 Chrome headless와 Playwright 1.63.0으로 실제 HTTP 페이지·DOM·iframe·다운로드·파일 업로드를 검사했습니다. 테스트 사이트와 검증실 자체의 확인이며 탐지기 성능이나 공모전 공식 점수를 의미하지 않습니다.

## 정적 검사와 재현성

`node source/manage.mjs check`로 사이트 1·2·3을 검사했습니다. 사이트 3은 HTML 94개, 로컬 링크·자산·프레임 참조 1,205개, 대상 전용 배포 파일 99개의 원본 일치 검사를 통과했습니다. 외부·인라인 JavaScript 구문, UTF-8 선언, 사례 ID 유일성, 소스 정의와 정답표·검증실 manifest 일치, 대상에서 정답 자료로의 링크 부재를 확인했습니다.

콘텐츠 64개는 광고 포함 48개와 정상 16개입니다. 광고 요소 52개와 정상 대조 요소 16개를 합친 DOM 검사 대상은 68개입니다. 기대 findings는 68건(HOMOGLYPH 14·JAMO 15·TRANSPARENT 20·OFFSCREEN 19)입니다. 요소 수와 findings 수가 같은 것은 이번 구성의 결과이며 항상 같다고 가정하지 않습니다.

콘텐츠 HTML 61개, 프레임 HTML 15개, 메뉴·안내·목록 HTML 17개로 대상 HTML은 93개이며 검증실을 포함하면 94개입니다. 쿼리 분기 4개는 하나의 물리 문서로 제공합니다.

사이트 3 재빌드 전후 dist·reference·test-site-3와 루트 목록의 파일 206개 SHA-256이 모두 동일했습니다. 공통 회귀 검사 `node --test source/site-tools.test.mjs`도 5개 통과했습니다. Git 변경은 루트 README·목록·사이트 등록과 새 프로젝트·배포본에 한정되며, 기존 사이트 1·2 파일은 변경하지 않았습니다.

원본·배포본 텍스트 파일 223개의 UTF-8 디코딩과 BOM 부재도 확인했습니다. Git 공백 검사는 오류가 없었습니다.

## 완료 범위와 한계

실행 가능한 소스, 정적 dist, 대상 전용 test-site-3, 정답표, README·제작 근거·검증 기록을 준비했습니다. 기존 폴더 형식을 유지했으며 별도 release·루트 tmp·압축 산출물을 추가하지 않았습니다. 개발 검사 후 임시 node_modules를 정리했습니다. 온라인 배포·커밋·push는 수행하지 않았습니다.

이 환경은 동일 출처의 정적 페이지와 고정 지연 DOM·iframe을 시험합니다. 교차 출처 프레임, 로그인, 서버 리다이렉트, CAPTCHA, Shadow DOM, 이미지 OCR, 실제 탐지 모델·실행 파일과 대규모 성능은 검사하지 않습니다. 검증실은 공식 점수를 계산하지 않으며 파일의 선언 시간을 독립 측정값으로 쓰지 않습니다.

링크 도달 검사 상한은 250 URL, 결과 파일 비교 상한은 5MB·10,000개 findings입니다. 검증실 분리는 접근 통제가 아니므로 정답 비공개 평가에는 대상 폴더만 제공해야 합니다.
