# 사이트 3 제작 근거와 명세

## 적용한 요청과 기존 코드

사이트 1·2에서 사용한 정적 배포 형식과 공통 사이트 관리 코드를 유지합니다. 사용자의 후속 요청에 따라 사이트 3을 추가하며, 이전에 위임된 제작 명세의 기관·규모·디자인은 이번 콘텐츠에 맞춰 정했습니다.

`source/sites.json`에 사이트를 등록하고 기존 `manage.mjs`·`site-tools.mjs`를 사용합니다. 사이트 2의 검증실 원본과 정적 검사·파일 서버를 재사용했습니다. 새 대상 페이지 생성기·콘텐츠·CSS·SVG·브라우저 검사는 해솔 프로젝트에 두고 기존 사이트 1·2의 탐지 대상은 수정하지 않습니다.

## 모집요강과 프롬프트의 적용

이 저장소에서 이미 분석한 첨부 모집요강과 [사이트 2 분석](../daon-library-ad-lab/REQUIREMENTS.md)을 이어서 적용했습니다. 최신 공고 변경을 조회한 결과가 아니며 공식 심사 사이트를 재현했다고 주장하지 않습니다.

- 단일 진입 URL에서 게시글·댓글·동적 DOM·iframe을 탐색하도록 구성합니다.
- 필수 HOMOGLYPH·JAMO·TRANSPARENT·OFFSCREEN을 모두 포함합니다.
- 결과 한 건은 부모 URL+실제 요소 위치+기법이며 복합 기법은 각각 별도 결과입니다.
- 정답표에 정규화 전 원문·유일한 선택자·프레임 경로·생성 지연을 기록합니다.
- 쿼리 값은 보존하고 파라미터 순서·fragment 및 요강의 프로토콜·끝 슬래시 비교 규칙을 반영합니다.
- UTF-8 BOM 없는 예상 결과, 필수 meta/findings 구조와 브라우저 내부 결과 비교를 제공합니다.
- 직접 DOM 검사와 별개로 시작 URL에서의 링크 도달을 검사합니다.
- 자체 비율과 파일에 기록된 시간만 표시하며 공개되지 않은 공식 점수 환산식을 만들지 않습니다.

첨부 문서의 응모·서명·제출 안내는 공모전 자료의 내용입니다. 이번 작업 범위는 테스트 사이트 제작이며 참가 서류 작성·전송이나 탐지기 실행 파일 제작을 포함하지 않습니다. 기존 폴더 형식을 유지하라는 사용자의 요청에 따라 프롬프트의 ZIP 요구 대신 정적 배포 폴더를 제공합니다.

## 자체 시험 범위와 한계

기준 viewport·권장 대기·링크 깊이·페이지 수·정상 비중은 자체 시험 설계이며 공식 심사 조건이 아닙니다. 1800초는 요강의 실행 상한이며 사이트의 목표 대기 시간이 아닙니다. iframe은 부모 페이지 안에서 검사하고 독립 페이지로 중복 집계하지 않습니다. 화면 아래 일반 콘텐츠는 정상 대조이며 OFFSCREEN 정답으로 표시하지 않습니다.

교차 출처 프레임·인증·서버 리다이렉트·CAPTCHA·Shadow DOM·이미지 OCR·실제 거래를 포함하지 않습니다. 스타일 검사는 실제 DOM과 조상 computed style을 확인하며 광고 의미 분류 모델을 실행하지 않습니다. 검증실의 파일 크기·findings·링크 방문 상한은 팀 자체 도구의 제한입니다.
