# 코드·모집요강·프롬프트 분석과 제작 명세

## 1. 기존 저장소 분석

루트 `index.html`은 사이트 목록이며 기존 배포본은 `test-site-1/`, 원본은 `source/hanbit-civic-ad-lab/`입니다. Node 생성 스크립트와 순수 HTML/CSS/JS로 게시판·쿼리 분기·고정 지연·중첩 iframe·검증실을 구현했습니다. 기존 사례는 콘텐츠 47개, 광고 요소 35개, 정상 대조 12개, 기대 검출 40건입니다. 서버 API·프레임워크·DB 의존은 없습니다.

재사용한 부분은 기법 사례의 기본 설계, 정답표 스키마, 검증실의 공통 UI·CSS 및 실제 DOM 비교 알고리즘입니다. 사이트 2에는 새 기관·콘텐츠·목록과 탐색 구조·디자인을 적용했습니다. 기존 생성기는 dist/index.html을 읽는 방식이므로 사이트 2 생성기는 소스에서 전체 문서를 생성하도록 만들었습니다. 기존 검증실의 사례 개수를 페이지 수로 쓰는 표시를 고유 URL로 보강하고 정답 요소 수를 별도로 표시했습니다. 상대 iframe src는 프레임별 문서 주소에 대해 해석하며, 프레임의 실제 src와 로딩, 선택적 버전 필드 타입을 검사합니다. 푸시 전 검토에서 두 검증실의 배포 대상 주소 대응을 보완했습니다. 이후 여러 사이트를 확장할 수 있도록 두 프로젝트의 빌드·검사·서버와 검증실 주소를 source/sites.json 등록 정보에 연동했습니다. 사이트 1의 탐지 대상·사례·배포 폴더 구조는 유지했습니다.

## 2. 첨부 PDF 분석

자료: `공공 웹사이트 불법광고 탐지 도구 개발 공모전 모집요강.pdf` 18쪽. 전체 텍스트를 확인하고 5·6·10·11·12·13쪽의 표와 예시를 렌더링해 대조했습니다. 아래 내용은 **첨부 PDF 기준**이며 최신 공고 변경을 인터넷에서 조회한 결과는 아닙니다.

- 1–4쪽: 행정안전부 주최·NIA 주관, 접수 2026.09.14–10.23, 개인 또는 최대 5인 팀. 제출 서류·실행 파일·전체 소스·매뉴얼 요구, 비공개 통제 평가 사이트와 참가 유의사항을 설명합니다.
- 5쪽: 단일 URL에서 하위 페이지·게시글·댓글·iframe을 탐색하고 주요 기법 4종을 분류·위치 식별합니다. 결과 안내 화면과 별도의 `result.json`이 필요합니다.
- 6–7쪽: 적격평가는 검출 개수 45점, 정확도 35점, 시간 20점입니다. 30분 초과 시 시간 항목 0점. 본심사는 정량 50·실무 활용 20·도입 10·창의성 20점입니다. 상세 100점 환산식은 공개되지 않았습니다.
- 8–9쪽: Windows 11, GPU 없는 PC, 단일 진입 URL, 필수 결과 파일 생성. 상용 AI API 사용 시 외부 설정으로 키 교체가 가능해야 합니다.
- 10–14쪽: UTF-8 BOM 없는 JSON, 최상위 `meta`와 `findings`, 1건 단위는 URL+위치+기법입니다. 중첩 기법별 별도 객체, 같은 요소의 같은 기법은 1건. CSS 유일성·절대 iframe src·쿼리 보존·URL 중복 규칙·원문 필수 기록과 판정 제외를 명시합니다.
- 15–18쪽: 참가신청서·서약서·개인정보 동의서·기획서 양식입니다. 기획서는 5–10매 요구입니다.

PDF의 접수·연락·서명·제출 지시는 공모전 참가 안내를 설명하는 **자료 내용**입니다. 사용자가 이번에 요청한 것은 분석과 테스트 사이트 제작이므로 서류 작성·개인정보 기재·이메일 전송·응모·탐지기 구동 파일 제작을 수행하지 않습니다. PDF는 테스트 사이트가 아니라 출품 탐지기의 요구사항을 설명합니다.

## 3. 프롬프트 분석

첨부 텍스트의 1번은 모의 환경·정적 배포·단일 진입 탐색·필수 4종·정상 대조·재현성의 공통 원칙입니다. 2번은 예시 placeholder를 채워야 하는 이번 사이트의 명세이며 사용자가 설계를 위임했습니다. 3번은 검증실·정답표·다운로드·브라우저 자체 검사·결과 비교·문서와 ZIP의 구체적 완료 조건입니다.

공통 탐지 요건에서 프롬프트와 PDF의 실질적 충돌은 없습니다. 이후 사용자가 기존 사이트 1의 폴더 형식을 유지하고 새 release 폴더를 추가하지 말라고 요청했으므로 ZIP 산출물 요구 대신 기존 정적 배포 폴더 형식을 따릅니다. 프롬프트의 사이트 크기, 정상 사례 비중, 지연, 1440×1000 viewport, 자체 정탐 비율은 자체 시험 규칙이며 공식 심사 조건이 아닙니다. 0초 예상 결과는 합성 예시로 안내합니다. 프레임은 PDF 13쪽 예시처럼 부모 URL과 내부 프레임 경로로 기록하며, 평가에서 iframe을 독립 URL로 재탐색하는 처리 여부까지 공식적으로 확정된 것으로 주장하지 않습니다.
