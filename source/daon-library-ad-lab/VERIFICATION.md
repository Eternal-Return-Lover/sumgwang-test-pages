검증일: 2026-10-05 (Asia/Seoul). 로컬 Chrome headless, Node.js 24.14.0. 사이트를 만든 뒤 실제 HTTP 서버·브라우저 DOM·파일 업로드로 검사했습니다. 검사는 사이트와 검증실의 자체 동작 확인이며 팀 탐지기의 성능 평가나 공모전 공식 점수가 아닙니다.

`node scripts/check.mjs` 통과. HTML 84개, 로컬 링크·자산·프레임 참조 1,067개 존재 확인. 외부 JS와 인라인 스크립트 구문, UTF-8, 정답표 일치, 고유 사례 ID, 대상에서 검증실로의 링크 부재를 확인했습니다.

콘텐츠 시나리오는 60개, 광고 포함 44개, 정상 콘텐츠 16개입니다. 정답 광고 요소 48개와 정상 대조 16개를 합쳐 DOM 검사 요소는 64개입니다. 기대 findings는 61건(HOMOGLYPH 12·JAMO 15·TRANSPARENT 18·OFFSCREEN 16)입니다. 57개 콘텐츠 HTML, 12개 iframe HTML, 14개 안내·목록·메뉴 HTML, 검증실 HTML 1개를 합쳐 84개입니다.

## 푸시 전 최종 검토

2026-10-05에 최종 코드로 다시 검사했습니다. 기존 사이트 1은 HTML 59개·참조 814개 정적 검사, 배포 파일 63개와 원본의 일치 검사를 통과했습니다. 사이트 2는 HTML 84개·참조 1,067개 검사, 대상 전용 88개 배포 파일과 원본의 일치 검사를 통과했습니다. 사이트 2의 빌드 전후 생성 파일·정답표·배포 파일 183개의 SHA-256 해시가 모두 같았습니다.

검증실이 소스의 dist 주소를 기준으로 잡아 실제 배포 결과를 거부하던 부분을 두 사이트에서 보완했습니다. 저장소 전체를 제공할 때 source/.../dist/lab 검증실은 해당 test-site-N을 검사 대상으로 삼습니다. 실제 Chrome에서 사이트 1 배포 주소의 완전한 정답은 TP40/FN0/FP0, 사이트 2는 TP61/FN0/FP0으로 통과했습니다. 사이트 2의 비교 입력 17종, DOM 64/64, 링크 도달 60/60, 공개 경로의 3단계 프레임, 대상 경로의 검증실 부재, 데스크톱·모바일 화면도 확인했습니다. 브라우저 JavaScript 오류는 0개였습니다.

UTF-8/BOM 검사에서 텍스트 파일 198개에 인코딩 오류가 없었으며, 알려진 비밀키 패턴 검색에서 일치 항목이 없었습니다. 루트 README의 두 사이트 주소·폴더 구조·시험 안내를 실제 구조에 맞춰 정리했습니다. Git 변경의 공백 오류가 없고, release·루트 tmp 및 압축 산출물이 남아 있지 않습니다. 검증 의존성 node_modules는 Git 제외 대상으로 확인하고 검증 후 정리했습니다. 온라인 배포·커밋·push는 수행하지 않았습니다.

## 여러 사이트 확장 검증 (2026-10-05)

- `node source/manage.mjs build`와 `check`: 두 사이트 통과. 사이트 1은 배포 63파일·기대 검출 40건, 사이트 2는 88파일·61건으로 유지됩니다.
- 전체 재빌드 전후 생성·정답·배포 파일과 루트 목록 315개의 SHA-256이 동일합니다.
- `node --test source/site-tools.test.mjs`: 5개 검사 통과. 2/10/11 숫자 정렬, 등록 충돌·잘못된 경로 거부, 사이트 10 배포 동기화·lab 제외·다른 사이트 보존, 두 검증실의 2/10/11/100 번호와 루트·저장소 하위 경로 계산, 다른 작업 폴더에서의 관리 명령과 없는 번호 거부를 확인했습니다.

## 완료 범위와 한계

전체 소스·dist·저장소 test-site-2 배포본·정답표·문서를 준비했고 로컬 서버를 실행했습니다. 후속 요청에 따라 사이트 1과 같은 폴더 형식으로 정리했습니다. test-site-2에는 탐지 대상 88개 파일만 두며, 검증실은 source 아래의 dist/lab에 보관합니다. 추가했던 압축 산출물과 임시 도구 폴더는 제거했습니다. **온라인 호스팅 업로드와 Git push는 하지 않았습니다.** Windows 11 출품 탐지기 실행 파일과 참가 서류는 이번 요청의 산출물이 아닙니다.

교차 출처 iframe·인증·리다이렉트·서버 세션은 시험하지 않습니다. 이 소규모 환경의 검사 통과가 비공개 공식 사이트에서의 성능이나 30분 내 처리 성능을 보장하지 않습니다. 기록된 실행 시간은 업로드 파일의 선언값이며 독립 측정한 탐지기 시간으로 사용하지 않습니다. 예시 결과 0초는 합성값입니다.

현재 정답 검사는 실제 DOM의 요소와 조상 스타일을 확인하지만 시각적 픽셀 분석이나 광고 의미 판별 모델을 실행하지 않습니다. 링크 검사 상한은 자체적으로 250 URL입니다. 파일 비교는 최대 5MB·10,000개 findings를 지원합니다. 검증실 분리는 접근 제한이 아니므로 정답 비공개 배포에는 탐지 대상 폴더만 배포하고 소스를 비공개로 보관해야 합니다.
